Setiap track memiliki urutan bagian, pola kick, frasa bass, dan fill tersendiri. Sampel break tidak ditumpuk. Potongan paling cepat adalah eighth-note; groove tetap memiliki ruang. Track 01 mempertahankan tema bass yang dikenali dari No Warning, dengan aransemen dan drum yang diperbarui.

## Memainkan

Copy seluruh isi satu file ke https://strudel.cc/, Stop pola sebelumnya, lalu Play. Tunggu sampel selesai dimuat saat pemutaran pertama. Setiap file mandiri dan tidak memerlukan file track lain.

Untuk export penuh, gunakan rentang pada tabel dengan `START_CYCLE = 0` dan `LOOP = false`. Satu cycle adalah empat ketuk. Rentang export menyediakan empat cycle tambahan untuk ekor efek. Posisi setiap bagian dicantumkan di awal kode.

Sampel berasal dari TidalCycles/Dirt-Samples dan memerlukan internet pada pemuatan pertama. Audio QA memakai sampel sumber yang sama dan mesin Superdough; pemeriksaan pola mencakup aransemen penuh, sedangkan render audio mencakup cuplikan build/drop. Ini belum merupakan WAV master album penuh.

Versi sebelum revisi tetap tersedia di direktori utama repository.
